# MSCS532 Assignment 3

This repository contains implementations of QuickSort and a Hash Table.

## How to Run

### QuickSort Implementation
```powershell
python .\quickSort.py
```

### Hash Table Implementation
```powershell
python .\hashing.py
```

The hash table program will run a performance test that:
- Adds 10,000 items
- Performs searches on existing and non-existing keys
- Deletes some keys
- Shows timing results
